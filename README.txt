NORMALISATION LAB - LOCAL CLASSROOM VERSION

1. Double-click index.html to open it in a browser.
2. Use the top tabs or the left/right arrow keys to move through the lesson.
3. Select "Play: Which normal form?" to run six diagnosis cases with the class.
4. Let students vote, optionally reveal a clue, then select an answer.
5. Select "Open worked example" to jump from a case to its full transformation.
6. Select "Reveal the dependency" after students answer the discussion prompt.
7. Select "Presenter view" to enlarge the lesson and hide the facilitator panel on a projector.

No internet connection or installation is required.
